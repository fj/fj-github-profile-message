# fj-github-profile-message

The commits in this repository draw the text in `MESSAGE.md` on the contribution graph of [@fj](https://github.com/fj). The [github-profile-message](https://github.com/fj/github-profile-message) action rewrites the history each day at 00:00 UTC.

To change the message, edit `MESSAGE.md` and run the **Paint profile message** workflow.
